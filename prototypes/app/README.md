## 交互范围

生产／训练模块切换（切换进入对应模块任务页）、每个模块的任务／项目／预制／模板导航、全局工具（模型、监控与日志、设置）、主题偏好；任务页保留检索与筛选、详情抽屉、生产暂停／恢复、取消／重试、生产终态多选与删除确认、错误复制；移动端经底部导航与「工具」面板到达全部入口。

所有任务与列表信息均为手工编写的演示数据。操作仅更新浏览器内存，刷新恢复初始任务；主题偏好与最近导航保存在浏览器。没有连接业务 API、数据库、ComfyUI 或训练执行器，也没有实际图片与模型字节下载。项目、预制、模板、模型、监控与设置页面为只读演示内容，其新建、编辑、扫描、保存等业务动作不在本轮范围。

训练不提供暂停；素材任务删除因 Q-01 未决而不制作。训练恢复遵守全应用最多一个等待／执行训练运行。生产重试／恢复从头执行，素材重试补缺；停止动作在原型内立即完成，真实异步停止、失败与冲突留给后续接入。

## 方向约束

核心：以唯一当前执行任务为关注中心，队列负责解释等待，历史负责检索。

视觉：继承 design-demo 的深浅中性色、青绿与粉色、透明面板、细边框、`Geist` 数字和紧凑控制。它是已有风格的延伸，不开启替代风格选案。

使用顺序：查看进度，判断谁在等待，检索过去任务，并在同一上下文完成恢复或取消。

首屏：桌面左侧为品牌、生产／训练模式切换、当前模块导航（任务／项目／预制／模板）与全局工具（模型／监控与日志／设置）、底部为外观偏好。手机为底部导航：模式切换、当前模块四个入口与「工具」面板。首次进入或导航失效回到生产任务；模块切换进入对应模块任务范围。

结构：用户已指定组件实验室和 F01–F08；直接代码制作原型，不生成新的视觉风格竞选。

完成条件：以实际桌面、手机和深浅主题截图及交互验证结束；评审与设计记录只代表本轮原型。

## 约束落实

- F01/F02：产品页不出现制作说明和装饰副标题；这些说明仅写在本文。
- F03：页头定位一次，当前任务状态一次；详情是独立阅读上下文；模块与全局工具分组各有职责。
- F04：数据仅一个执行中任务；当前任务不受列表筛选隐藏。
- F05：执行时间、输入参数、输出分组独立。
- F06：同尺寸线性图标、固定行高与同行对齐。
- F07：任务名称是唯一详情入口；复选框与操作按钮独立；导航中不叠加同义入口。
- F08：队列紧凑行、历史表格，长名称允许换行；侧栏按模块与工具分组，不制作大面积空白任务卡。

跨模块／项目时保留全局当前执行区是本轮暂定方案，已向用户询问，尚未视为确认。列表筛选仅作用于等待队列与任务记录。
