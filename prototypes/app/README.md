# 新版应用完整原型（独立 PrimeReact 版）

2026-09-16，按评审要求重建：原型与应用本体彻底分离，放在仓库的独立原型目录 `prototypes/app/`，使用文档要求的 `PrimeReact` 组件库，不依赖、不 `import` 任何 `src/`（应用本体）代码。视觉依据是设计功能规划与 `PrimeReact` 组件体系；本轮结果不代表正式前端已实施或设计已获认可。

运行：在本目录执行 `npm install` 后 `npm run dev`，打开 `http://127.0.0.1:4318/`（首次或空地址进入生产任务页）。

## 本轮范围

- 按新版功能规划（R02-01／N-01／N-02／U-02）搭建导航：工作区（任务／项目／预制／模板）、资源（模型）、系统（设置）；生产／训练按工作模式切换，切换进入对应模块任务范围；无概览首页与退出登录入口。
- 任务页保留上一轮已复核的行为：当前执行、等待队列、任务记录、详情抽屉、暂停／恢复／取消／重试与删除确认、训练单运行阻止、错误复制、选择与焦点行为。
- 项目、预制、模板、模型、监控与日志、设置六个入口为只读演示页；监控与日志入口放在设置页内。

## 组件库边界

- 基础组件全部来自 `PrimeReact`（按钮、状态徽标、面板、输入框、下拉选择、分段选择、复选框、进度条、抽屉、确认面板、消息提示等），图标为 `PrimeIcons`。不手写基础组件，也不维护独立的基础组件演示页。
- 组件定制走官方推荐路径：`theme/tokens.css` 是唯一语义令牌来源，`theme/theme-inputs.mjs` 把它映射到 `PrimeReact` 官方 v10 `Sass` 参数，`scripts/build-theme.mjs` 用仓库内固定的官方 `primereact-sass-theme` 快照生成 `src/theme.generated.css`（`npm run theme:build` 生成，`theme:check` 校验新鲜度）。全局行为用库的 Provider 公开配置，组件级例外只出现在公开的 `pt` 插槽或公开属性上。
- `src/styles.css` 只负责外壳、页面与列表布局以及玻璃效果，不覆盖组件内部样式；状态语义用 `Tag` 的 `severity` 公开属性表达。
- 主题默认实时跟随系统，仅提供浅色／深色两项：选择与系统当前外观不同的选项时固定，选择相同选项时恢复跟随。主题与工作模式保存在 `localStorage` 的 `cm-prototype-preference-v1`，并写入根元素的 `data-theme` 与 `data-module`（生成主题按该作用域生效），不与应用本体的存储键共享。

## 与应用本体的关系

- 本目录拥有自己的 `package.json`、`node_modules` 与开发服务（`Vite`），全部外部依赖独立管理；与应用本体的依赖冗余可以接受。
- 源码不 import 任何 `src/**`、`src/proxy.ts`、应用根布局、API、服务或业务功能；应用本体也不引用本目录。生产业务路由、运行时、数据库和服务均未修改。
- 组件库与非侵入式定制契约见[新版前端基础规范](../../docs/design/prototypes/design-foundations.md)；具体颜色、字体与尺寸属视觉风格内容，不写入该契约。

## 演示数据与交互

所有任务与列表信息均为手工编写的演示数据。操作仅更新浏览器内存，刷新恢复初始任务；主题与工作模式保存在浏览器。没有连接业务 API、数据库、ComfyUI 或训练执行器，也没有实际图片与模型字节下载。

训练不提供暂停；素材任务删除因 Q-01 未决而不制作。训练恢复遵守全应用最多一个等待／执行训练运行。生产重试／恢复从头执行；停止动作在原型内立即完成，真实异步停止、失败与冲突留给后续接入。

## 方向约束

- 产品页不出现“原型／示例数据／占位”等制作说明，这些说明只写在本文。
- 页头定位一次，当前任务状态一次；详情是独立阅读上下文；设置页不重复展示主题状态。
- 数据仅一个执行中任务；当前任务不受列表筛选隐藏。
- 执行时间、输入参数、输出分组独立。
- 图标全部来自 PrimeIcons，与文字行高对齐。
- 任务名称是唯一详情入口；复选框与操作按钮独立；导航不叠加同义入口。
- 队列紧凑行、历史网格行，长名称截断可点开详情；不制作大面积空白任务卡。

跨模块／项目时保留全局当前执行区是本轮暂定方案，尚未视为确认。列表筛选仅作用于等待队列与任务记录。

## 文件边界

`prototypes/app/**` 拥有本原型的入口、页面、外壳与演示数据；应用本体与文档组件体系均未修改。仓库清单与设计文档仅登记本目录。
