# 基础组件与任务页原型

2026-09-16，新一轮设计，待用户评审。视觉依据是当前 组件实验室 源码；本轮结果不代表正式前端已实施或设计已获认可。

启动：在仓库根目录执行 `node prototypes/task-workspace/server.mjs`。

- 任务页：<http://127.0.0.1:4318/>
- 基础组件：<http://127.0.0.1:4318/components.html>

## 交互范围

生产／训练任务切换、名称与编号检索、项目／时间／类型筛选、历史状态与排序、详情抽屉、生产暂停／恢复、取消／重试、生产终态多选与删除确认、错误复制、深浅主题。基础组件页提供按钮、状态、输入校验、选择、进度、反馈、确认对话框、空状态。

所有任务与产物信息均为手工编写的演示数据。操作仅更新浏览器内存，刷新恢复初始任务；主题偏好保存在浏览器。没有连接业务 API、数据库、ComfyUI 或训练执行器，也没有实际图片与模型字节下载。结果区域本轮展示文件信息，不宣称完成图片审核器、LoRA 产物管理或全部高级参数编辑。

训练不提供暂停；素材任务删除因 Q-01 未决而不制作。训练恢复遵守全应用最多一个等待／执行训练运行。生产重试／恢复从头执行，素材重试补缺；停止动作在原型内立即完成，真实异步停止、失败与冲突留给后续接入。

## 方向约束

核心：以唯一当前执行任务为关注中心，队列负责解释等待，历史负责检索。

视觉：继承 design-demo 的深浅中性色、青绿与粉色、透明面板、细边框、`Geist` 数字和紧凑控制。它是已有风格的延伸，不开启替代风格选案。

使用顺序：查看进度，判断谁在等待，检索过去任务，并在同一上下文完成恢复或取消。

首屏：左侧模块导航；顶部单一标题；当前执行横向面板；紧凑筛选、队列与表格。手机变为底部导航，保留名称和状态。

结构：用户已指定 组件实验室 和 F01–F08；直接代码制作原型，不生成新的视觉风格竞选。

完成条件：以实际桌面、手机和深浅主题截图及交互验证结束；评审与设计记录只代表本轮原型。

## 约束落实

- F01/F02：产品页不出现制作说明和装饰副标题；这些说明仅写在本文。
- F03：页头定位一次，当前任务状态一次；详情是独立阅读上下文。
- F04：数据仅一个执行中任务；当前任务不受列表筛选隐藏。
- F05：执行时间、输入参数、输出分组独立。
- F06：同尺寸线性图标、固定行高与同行对齐。
- F07：任务名称是唯一详情入口；复选框与操作按钮独立。
- F08：队列紧凑行、历史表格，长名称允许换行；不制作大面积空白任务卡。

跨模块／项目时保留全局当前执行区是本轮暂定方案，已向用户询问，尚未视为确认。列表筛选仅作用于等待队列与任务记录。

## 文件边界

独立 HTML/CSS/JavaScript；`ui.js` 为共用控件渲染，`ui.css` 为主题与组件样式，`data.js` 为独立样本。服务只开放显式文件白名单与现有 `Geist` 字体，不暴露仓库或环境配置。生产源码、运行时、数据库和服务均未修改。

## 本轮验证

- `Chrome` 实际查看 1440px 桌面、390px 手机、手机详情、基础组件、浅色训练页；900px 核对无横向溢出。内置浏览器截图受缩放影响，最终视觉证据改用 `Chrome`。
- 浏览器验证：检索与失败详情、重试入队、模块切换、单训练并发阻止、删除范围确认及返回、暂停、键盘恢复、Escape 关闭与焦点返回；组件输入校验、分段选择、开关、对话框和主题切换。无控制台 warning/error。
- 回归：勾选失败任务后重试，选择被清除且任务进入队列；详情恢复后关闭，焦点回到重建后的任务名称入口。
- 独立复核结论：`ship`，仅表示可交付用户评审。删除范围、焦点、详情重复信息三项修复已核对。未获得用户设计批准。
- JavaScript 语法检查通过；产品／设计文档治理测试 19/19 通过。`docs:check` 为 0 错误、3 条无比较基线的语义复核提醒；未改业务 API、队列或 worker。
- 机械检测中的 `Geist` 提示按用户要求沿用既有字体；对话框内边距由子容器提供。进度条宽度动画已移除。遮罩使用透明纯色，避免模糊遮罩造成的截图捕获故障。
