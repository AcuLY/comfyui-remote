# 项目上下文与导航恢复

既有 `R02-02`，2026-09-12用户明确要求继续下一原型，2026-09-13授权“先处理已知的问题”。采用 `Operate` 模式，扩展 `R02-01` 外壳，沿用基础视觉与共享组件。范围、复盘 `I01`～`I14` 验收表和实际结果由 `docs/design/prototypes/reviews/R02-02.md` 维护；本轮已按所列范围完成修复及针对性验证，`R02-01/02` 均待用户审核。

原型从明确的项目来源样本开始；正式应用与模块切换的任务默认入口不变。生产项目页签为概览、小节、图片、任务；训练为概览、角色档案、参考图、构图、训练素材、任务。使用原生面包屑与页签组件；来源返回和层级返回分开，长名称有完整标题，手机六项页签全部可达。

2026-09-12用户指出首稿功能和 UI/UX 理解偏差，要求对照旧前端与设计演示，并补充：各类卡片展示图片、能双列优先双列、体现文件夹操作。先修订当前契约，再在同一R02-02内实现；不新增任务号，也不将首稿验证当作本次通过依据。

内容卡片体现真实对象关系：项目展示最近结果，小节／构图展示自身图片；生产图片有独立结果、所属小节与来源任务。参考图有独立名称、用途和构图输入关系，训练素材按构图展示候选数、代表图、实际 `Caption` 及缺项。各页面可复用图片字节，不能复用同一业务记录后只改标题。训练运行保留独立 `TrainingRunSample` 输入快照和 `checkpoint` 产物，失败不清空输入，不用“没有输出图片”概括运行结果；项目级运行不伪造单一构图归属，每条样本可追溯实际构图。普通图片任务无输出时可展示明确标注的来源参考，详情输出区仍显示准确空态。

项目使用正常／归档生命周期，活动任务摘要另行显示；归档没有非终态任务，所有已呈现写入口及模型操作统一只读，选择含归档项目时全部批量写入口禁用并说明原因。生产图片任务使用七种真实状态；训练素材生成与训练运行分别保留五种真实状态、等待原因及不同结果语义。小节、构图及其他资源标识跨项目唯一，`module + resourceType + resourceId` 可定位声明类型及真实归属。

文件夹仅用于生产项目列表和生产项目内小节列表，分别遵循 `GEN-PROJ-003/004` 与 `GEN-SEC-006/007`：多级进入、路径返回、新建、改名及文件夹排序；单项／多选项目或小节拖入有效文件夹／根目录，小节同层拖排明确前／后插入。文件夹落点与排序落点区分，拖动已选项携带全部选择；跨对象范围、跨项目和只读目标不能写入。移动菜单及上移／下移是触屏和键盘等价入口，取消不改状态。本轮不增加生产项目手工展示排序，不将训练／任务分组改造成文件夹。旧记录排除拖放、多选和排序的契约已撤下，原轮验证仅作历史保存。

卡片及选择、菜单、对话框使用 `PrimeReact 10.9.9` 公开 `Card`／`Checkbox`／`Menu`／`Dialog`。已核对公开类型：`Tree` 负责树节点拖放，`DataTable` 负责表格行重排，`OrderList` 负责自身列表重排，不能直接提供当前图片网格跨文件夹多选拖放。应用层用原生 `HTML` 桌面拖放协调选择集合、有效落点和顺序，保留菜单／按钮替代路径；不把桌面拖放作为真机触控证据，也不复用暂停的 `R01-02` 通用组织假设。

根目录表示当前层，全部浏览表示跨文件夹完整集合；概览“查看全部”的数量及落点一致，全部项能辨认所在路径。来源项目／任务列表与当前小节列表分别保存查询、状态和范围；小节有实际搜索入口，文件夹进入／返回、详情／任务往返、刷新及浏览器前后不清掉原条件，按地址及资源恢复滚动和焦点。首稿摘要已取消；无效目标逐级回同模块最近有效父级并说明。

布局按真实卡片可读宽度优先双列，当前容器断点304px；本机浏览器375px、390px、393px视口已测双列，320px单列，均无横向溢出，390px移动菜单已实际操作。该断点仅适用于当前卡片组合，不外推到全部业务网格。长名称、图片、选择与菜单均需完整可用。普通触控控件40px，图标按钮、关闭及分页动作44px，可编辑输入16px；当前数字不由旧44px历史测量覆盖。

全部交互仅使用关联明确的静态图片和本地会话模拟数据。照片来源见 `docs/design/prototypes/public/media/context/SOURCES.txt`，不是真实用户图片、生成结果或训练素材。本轮补齐的组织能力不等于 `R05-02`／`R05-05` 全任务和生命周期获批；删除、归档流程、参数编辑、完整图片审核、素材编辑及生成／训练正式执行仍在对应任务。训练不恢复 `DatasetRevision`、`DatasetVersion` 或候选图 `reviewStatus`；共享外壳仍为 `navigation-shell.jsx`。

本轮针对性验证已完成：归档 `p10` 没有移动／新建文件夹／拖动入口；独立参考图、图片与来源任务往返保留集合条件，训练材料有实际候选数和缺项，失败训练仍显示3份输入快照；鼠标多选项目拖入文件夹、小节前插排序、390px批量移动回根目录及刷新、键盘 `Enter` 排序均已操作。查询与文件夹范围、小节与任务页签切换、全部6项及路径文案已复核。唯一身份、归档写保护、文件夹排序及其余恢复边界由模型测试补验；每份训练样本来源构图链接新增后的证据是源码核对。

29项模型测试、29项治理测试和原型构建通过，所选源码机械检测输出 `[]`；最终合并门禁结果见主记录。2026-09-12首稿及图片／文件夹首轮修订验证仍只作历史。未覆盖真机触屏、读屏、完整主题／模块／视口矩阵与全部历史／滚动组合；工程检查、针对性修复和用户设计批准分别记录。
