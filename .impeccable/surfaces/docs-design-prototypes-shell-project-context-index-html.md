# 项目上下文与导航恢复

既有R02-02，2026-09-12用户明确要求继续下一原型；采用 `Operate` 模式，扩展R02-01外壳，沿用基础视觉与共享组件，非新视觉世界。范围和当前契约由 docs/design/prototypes/reviews/R02-02.md 维护。

原型从明确的项目来源样本开始；正式应用与模块切换的任务默认入口不变。生产项目页签为概览、小节、图片、任务；训练为概览、角色档案、参考图、构图、训练素材、任务。使用原生面包屑与页签组件；来源返回和层级返回分开，长名称有完整标题，手机六项页签全部可达。

2026-09-12用户指出首稿功能和 UI/UX 理解偏差，要求对照旧前端与设计演示，并补充：各类卡片展示图片、能双列优先双列、体现文件夹操作。先修订当前契约，再在同一R02-02内实现；不新增任务号，也不将首稿验证当作本次通过依据。

内容卡片要体现真实对象关系：项目展示最近结果，小节／构图展示自己的候选或代表图，图片任务优先展示本次输出，训练运行的样本图明确标注用途。尚无输出的任务卡可展示来源图，必须标注“来源参考 · 尚无输出”；没有任何可展示图片才使用卡内空态，任务详情输出区在无输出时始终显示空态。项目记录不得同时充当任务记录；任务提供所属项目及实际来源小节／构图跳转，项目级训练运行不伪造单一构图归属。卡片按可用内容宽度优先双列，当前目标为内容宽度至少344px两列、320px视口单列；长名称自然完整换行，操作菜单及图片在双列下仍完整可用。

文件夹只用于生产项目列表和生产项目内小节列表，分别遵循 GEN-PROJ-003～004 与 GEN-SEC-007：进入多级目录、路径返回、新建、改名、移动到文件夹或根目录，取消不改状态。项目和小节目的地范围隔离，不将训练排序、构图或任务分组改造成文件夹。本次验证“移动到”的键盘／触屏流程，不声称完成完整拖放、多选、排序与删除设计。

仅使用关联明确的静态样本图片及本地会话模拟数据，无真实业务写接口或生产数据修改。照片来源和用途记录在 `docs/design/prototypes/public/media/context/SOURCES.txt`，不是真实用户图片、生成结果或训练素材。搜索、状态筛选及文件夹范围写入片段，滚动与焦点按地址／资源保存；深链、刷新、前后和返回列表保留状态与定位。首稿的导航摘要已取消，当前没有摘要展开及其恢复状态。无效页签、子项、项目及文件夹逐级回到同模块最近有效父级，并就地说明。

项目参数编辑、完整图片审核、素材编辑与生成／训练执行不在本次范围。训练保留新版构图／代表图／说明文本关系，不恢复 `DatasetRevision`、`DatasetVersion` 或候选图 `reviewStatus`。复用 `navigation-shell.jsx`，避免复制另一套侧栏、底栏、主题和更多逻辑；本项不会使R02-01或其他业务任务自动获批。
