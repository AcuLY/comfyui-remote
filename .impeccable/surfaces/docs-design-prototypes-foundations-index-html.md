# 基础设计原型

目标：仅为 `docs/design/prototypes/**` 的基础审核样本，采用代码制作。用户已确认从 `Figma` 改为 HTML，并先处理基础组件、色彩与字体；具体数值仍待审核。保留已确认的双模块青绿/粉色、系统主题与 `PrimeReact v10` 方向。本次是该方向内的基础样本，未进行新品牌方向投票。

## 方向约定

主题：让用户通过真实控件比较设计选择；优先清晰、可操作的基础样本，不增加业务页面。

视觉体系：柔和中性表面，青绿与粉色对等，独立状态语义；中文 `Noto Sans SC`、英文 `Geist`、代码 `IBM Plex Mono`。

使用路径：切换主题和模块、试用输入与反馈、按 F-01～F-14 提出调整。

首屏：顶部全局切换，桌面左侧目录，中间色板与可操作表单；手机改为单列。

形式：在已确认方向中直接制作基础展示画布；属于明确限定的小范围任务，不进行概念抽签。

完成条件：完成独立收尾审查、修正结论和限定原型范围的设计记录；所有视觉选择保持待用户审核。此次无交付位图素材，截图仅作验证。
