范围：`R01-01`，`Operate` 模式。用户于2026-09-09确认 `30fd53db` 列表样本，该历史确认保留；后续共享主题与交互修订单独验证及审核，不扩大为统一主题全部状态获批。用户在长时间创作工作中需要读清内容、找出记录并明确操作范围；本稿使用固定虚构记录，独立于正式业务页面。`R01-02` 暂停，不作为“下一项”；当前 `R02-01/02` 均待用户审核。

## 方向约定

主题：搜索、筛选、选择和分页围绕同一份列表展开；本页选择有明确数量和范围。

视觉：模块色按用户本轮指定的 `#176E5A`／`#A23F5D` 色相更新，中性明暗表面和字体沿用基础规范。全原型固定标准密度，桌面通用控件高 36px、行垂直内边距 12px，不提供密度切换或保存密度偏好；手机／粗指针普通控件40px，可编辑输入字号16px，纯图标按钮、关闭及分页动作保留真实44px，不添加透明热区。值源仍为 `tokens.css`，不增加装饰性图像。

使用路径：搜索或筛选 → 单项／本页多选 → 复制名称或取消 → 翻页；切换范围清空选择。预览控制单独置于列表外。

首屏：桌面保留状态预览，表头与六列内容均有骨架；手机将主题、模块与状态收进顶栏“预览”，压缩标题和工具栏，先呈现列表卡片。手机使用选择条和卡片对应的骨架，不留下空表头区域。手机工具栏内边距12px、字段间距8px；普通输入40px，搜索旁重置与独立复制按钮保留真实44px，组合垂直居中。尺寸由统一主题生成，不覆盖组件内部图标或标签。

形式：已确认方向内的代码组件组合，沿用 R01-01 的明确任务，不再进行概念选择。关键反馈是选择后工具栏显示本页数量，颜色与模块一致。

完成状态：保留已确认的列表样本与对应验证。2026-09-13已修复系统主题追上已固定颜色后再次点击当前色的恢复路径；鼠标、空格及 `Enter` 三种触发均回到实时跟随，所测共享焦点清晰，过期入口文案已同步。实际范围记入 `docs/design/prototypes/reviews/R02-02.md` 的复盘 `I09/I10/I14` 验收，不宣称完整设备／主题矩阵通过。共享修订待用户审核，不把列表重新写成从未确认的候选稿，也不扩大确认范围。无交付位图素材。
