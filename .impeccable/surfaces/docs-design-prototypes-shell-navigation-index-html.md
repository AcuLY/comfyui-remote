# 全局导航外壳

范围为事前已登记的R02-01，`Operate`模式；任务及制作边界见 docs/design/prototypes/reviews/R02-01.md。该记录只约束R02-01；R02-02已于2026-09-12单独获准制作，复用外壳而不改变此处导航基线。

沿用已确认的基础方向、字号及当前40px触控普通控件／44px图标控件；基础统一主题修订仍待用户审核。桌面侧栏顶部模块、中部四入口、底部全局工具及主题快捷按钮。2026-09-10用户指令覆盖IA-06的手机顶部模块布局：手机顶部留给页面实际操作，模块切换、四入口及更多共同放到底部。两模块在桌面与手机均按任务、项目、预制、模板排序。其余业务边界保留，不重新选择视觉世界或无关版式。

本轮呈现以2026-09-11最新反馈为准：宽屏展开侧栏，窄屏默认图标栏并支持手动收放。模块选择统一使用外层轨道与原生按钮，展开横向文字、收起纵向图标；手机更多同样使用模块轨道，移除当前模块菜单。更多及预览设置中的浅色／深色复用相同轨道交互，侧栏明暗快捷按钮保留。完整按钮命中区须与视觉一致，不能用`width: auto`压缩纯图标按钮或用透明层补救。

手机底部保留任务、项目、预制、模板、更多五项单排，移除整项选中外框，活动底色限定在图标区域并保留文字与边缘留白。更多为视口全宽、内容自适应的底部面板；通过对话框公开的关闭标题区属性替换高大标题区，顶部同排呈现模块轨道、太阳／月亮主题轨道与关闭，不显示“模块”或“主题”标签；下方三个紧凑全局工具并排；内容起始16px内边距，组间距清楚。保留模态焦点和键盘关闭。顶部仍留页面操作，主内容保持对应留白。

导航侧栏、底栏、轨道与分隔线使用局部纯灰背景和边框变量；活动态不复用偏蓝灰的`border-control`，保留已批准的生产绿与训练粉。不改变全局基础色板，不修改组件内部图标／标签结构。这些最新规则覆盖历史模块菜单、默认对话框标题区及大块底栏选中样式；旧版验证不代表新版通过。

交互只包含模块任务入口和片段导航，首次进入生产任务；不实现项目页签、查询／滚动恢复或真实鉴权。原生链接支持浏览器历史，按最新用户要求移除退出登录入口及模拟逻辑，此决定覆盖IA-05/06的旧记录。侧栏主题快捷切换遵循共享偏好：选择相反系统色时持久固定，选择相同系统色时恢复跟随。完成以桌面、窄屏、手机及短横屏实测、实际限制记录和用户待审核稿为准，不自标设计已确认。

点击生产／训练轨道统一进入对应任务页，替代旧模块上次入口记忆；直接页面地址和刷新仍保留当前页。

2026-09-11收放修订：侧栏宽度与图标位移共用单一动画进度；保留按钮结构，通过公开插槽同步位置和文字显隐。收起立即隐藏展开文字、展开按剩余空间渐显；侧栏边界裁切，快速反向从当前进度继续。

切换模块保持更多面板打开；选择具体工具、关闭、遮罩和退出键才收起。主题仅浅／深：默认跟随系统，选择相反色固定，选回系统当前色恢复跟随；系统变化本身不解除固定。此规则替代旧显式系统入口。

手机布局底栏与更多不显示悬停底色，保留按下、选中和键盘焦点；鼠标桌面侧栏保留悬停。更多工具行普通窄屏44px高，不足400px时52px高，移除独立主题行。

底栏使用原生 `TabMenu` 的受控状态、菜单数据和公开插槽，保留五项手机排列与更多面板。文字统一500字重，图标／文字与底色共享160毫秒渐变进度；不叠加选中后加粗，不修改组件库源码。

2026-09-13已修复并针对性验证：按住更多面板中未选模块时，背景由透明变为 `rgb(250, 230, 236)`，前景同步变化，所测84.91×44px计算尺寸不变；浅色更多面板边框为导航局部中性灰 `#e0e0e0`。结果与验证范围统一记入 `docs/design/prototypes/reviews/R02-02.md` 的复盘 `I11/I12`，不外推为完整主题矩阵通过。`R02-01/02` 各自保持待用户审核，`R01-01` 确认历史保留，`R01-02` 暂停。
