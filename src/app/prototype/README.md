# 新版应用完整原型

2026-09-16，从「基础组件与任务页原型」重建为应用级完整原型，改用文档约束的组件库实现，待用户评审。视觉依据是组件实验室（design-demos）与共享组件外壳；本轮结果不代表正式前端已实施或设计已获认可。

访问：开发服务启动后打开 `/prototype/`（首次或空地址回到 `/prototype/production/tasks`）。

## 本轮范围

- 按新版功能规划（R02-01／N-01／N-02／U-02）在共享 `DesignDemoShell` 上搭建导航：工作区（任务／项目／预制／模板）、资源（模型）、系统（设置）；生产／训练按工作模式切换，切换进入对应模块任务范围；无概览首页与退出登录入口。
- 任务页原型按上一轮已复核行为迁入组件库实现：当前执行、等待队列、任务记录、详情抽屉（基础 `Sheet`）、暂停／恢复／取消／重试与删除确认、训练单运行阻止、错误复制、选择与焦点行为。
- 项目、预制、模板、模型、监控与日志、设置六个入口提供只读演示页；监控与日志入口放在设置页内（沿用组件外壳的移动端槽位契约）。

## 组件库边界

- 基础组件全部来自文档约束的组件库：`src/components/design-demo-ui/**`（按钮、状态徽标、面板、字段、悬浮选择、分段选择、复选框等）与 `src/components/ui/sheet`（抽屉与确认面板）；图标为 `lucide-react`（`components.json` 指定）。不再自实现基础组件，也不再维护独立的基础组件演示页。
- 页面布局与列表行是本原型功能自有界面（与组件实验室功能页同一做法），只使用组件库公开的 `--demo-*` 主题变量。
- 主题为组件外壳的深浅切换（存储键与文档属性与组件实验室一致，Cookie 路径限定 `/prototype`）；工作模式沿用外壳的存储键与变更事件。组件库未修改。

## 演示数据与交互

所有任务与列表信息均为手工编写的演示数据。操作仅更新浏览器内存，刷新恢复初始任务；主题与工作模式保存在浏览器。没有连接业务 API、数据库、ComfyUI 或训练执行器，也没有实际图片与模型字节下载。项目、预制、模板、模型、监控与设置页面为只读演示内容，其新建、编辑、扫描、保存等业务动作不在本轮范围。

训练不提供暂停；素材任务删除因 Q-01 未决而不制作。训练恢复遵守全应用最多一个等待／执行训练运行。生产重试／恢复从头执行，素材重试补缺；停止动作在原型内立即完成，真实异步停止、失败与冲突留给后续接入。

## 方向约束

核心：以唯一当前执行任务为关注中心，队列负责解释等待，历史负责检索。

使用顺序：查看进度，判断谁在等待，检索过去任务，并在同一上下文完成恢复或取消。

首屏：共享外壳侧栏（品牌、工作区／资源／系统分组、主题与 `SFW` 开关）；页头承载页面定位；任务页以当前执行面板开头，随后是筛选、队列与记录。手机沿用外壳底部导航与抽屉。

## 约束落实

- F01/F02：产品页不出现制作说明和装饰副标题；这些说明仅写在本文。
- F03：页头定位一次，当前任务状态一次；详情是独立阅读上下文；设置页不重复展示主题状态。
- F04：数据仅一个执行中任务；当前任务不受列表筛选隐藏。
- F05：执行时间、输入参数、输出分组独立。
- F06：图标全部来自 `lucide-react`，与文字按组件库行高对齐。
- F07：任务名称是唯一详情入口；复选框与操作按钮独立；导航不叠加同义入口。
- F08：队列紧凑行、历史网格行，长名称截断可点开详情；不制作大面积空白任务卡。

跨模块／项目时保留全局当前执行区是本轮暂定方案，已向用户询问，尚未视为确认。列表筛选仅作用于等待队列与任务记录。

## 文件边界

`src/app/prototype/**` 拥有本原型的路由、页面与演示数据；共用组件库与共享外壳未修改。根布局仅把 `/prototype` 加入独立外壳前缀列表，并在[布局与密度](../../../docs/design/layout-and-density.md)中登记。生产业务路由、运行时、数据库和服务均未修改。
