## 共用状态矩阵

只对实际适用的页面补状态；不要求每个静态信息区机械增加空态或确认框。适用状态按对应业务范围核对。

| 编号 | 适用范围 | 必须可审核的状态与行为 |
| --- | --- | --- |
| V-01 | 业务内容读取 | 加载中、无数据／无筛选结果、局部加载失败与重试；长名称／路径／错误、不同数据量下仍能完成主要动作 |
| V-02 | 可编辑内容 | 未保存、保存中、成功、失败保留输入、字段错误、`409` 冲突；禁用原因、只读与禁用区别，恢复动作不覆盖其他 `scope` |
| V-03 | 主题偏好 | 系统实时跟随、持久手动选择及恢复跟随的行为一致；不规定主题外观 |
| V-04 | 可访问性与设备适用性 | 桌面、手机、键盘与触控均能完成适用业务；长内容可访问、相邻操作不遮挡；键盘顺序、可见焦点、关闭临时内容后恢复触发点、操作具名及减少动态效果 |
| V-05 | 列表与批量操作 | 桌面与手机均完成适用的搜索／筛选／排序、单选／多选／取消、选择工具条、分页／容量、拖放落点及替代移动操作、范围／数量、部分失败及可复制错误；反馈即时可见，局部失败不丢掉成功项和用户输入 |
| V-06 | 图片生成任务 | 未提交、已提交、运行中、已暂停、已完成、失败、已取消；暂停／取消请求中及实际停止失败；恢复明确从头执行，无部分成功正式结果 |
| V-07 | 图片等待与 `GPU` 协调 | 区分 ComfyUI 不可达、`GPU` 不可用／未知、训练占用、恢复等待／失败；创建任务不弹启停 ComfyUI 提示；空闲进程不阻止训练，已提交／运行图片任务参与互斥 |
| V-08 | 训练素材生成任务 | `pending`／`running`／`completed`／`failed`／`cancelled`；环境不可用；部分候选成功但数量不足为失败，重试补缺；无暂停，取消必须真实反馈 |
| V-09 | `LoRA` 训练运行 | `pending`／`running`／`completed`／`failed`／`cancelled`，等待图片任务／`GPU`／环境；全应用唯一活动训练；中断后显式重试，停止失败／失联不假称释放资源 |
| V-10 | 图片、模型与训练材料 | 图片加载／缺失／`SFW`、模型缺失／同类型替换、目录缺失、代表图有／无、`Caption` 有／无、`checkpoint` 文件清理但记录保留 |
| V-11 | 归档、删除与恢复 | 永久归档持续只读，浏览及允许的下载仍可用；非终态任务／引用阻止、具体保留／删除范围、逐项清理失败；不出现反归档 |
| V-12 | 路由与跨页状态 | 深链打开／刷新、前后导航、列表→详情→返回的筛选／页签／展开／滚动恢复、有效页面位置（点击模块仍进任务）、无效资源回父级；回收站与历史返回保留来源范围 |
