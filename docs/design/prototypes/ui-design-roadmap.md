# 新版前端 UI 设计路线

## 当前起点与使用方式

用户于 **2026-09-09** 确认 `R01-01` 的 `30fd53db` 版本，并要求继续下一项。当前进入 [R01-02 层级、手动排序与移动到](reviews/R01-02.md)，继续采用[基础统一主题](reviews/F-theme.md)。此前基础确认及[适配历史](reviews/F-responsive.md)保留；绿色／玫瑰粉色相、浅色纯白底色、字体、语义与固定标准密度继续有效。现行范围见[基础规范](design-foundations.md)与[基础清单](foundations/README.md)；桌面标准 36px，手机／粗指针普通控件 40px，可编辑输入字号 16px，纯图标按钮、关闭及分页动作保留真实 44px，不开放密度选择。

本文继续保存整个新版前端的覆盖和依赖顺序。**R01-01 已确认；当前只制作 R01-02 的文件夹层级定位、当前文件夹内容多选、手动顺序和“移动到”对话框。** 其他 `R01` 子项与业务页面不在本轮范围，列表确认不扩大为统一主题全部状态、`C03` 或整个 `R01` 完成。表中的“未开始”指新版 HTML 设计稿，不判断旧生产功能是否存在；64 个覆盖编号不等于 64 个独立路由或已完成页面。

每次只选一个批次内的明确子项，先稳定组件与主视图，并在同一轮补齐适用浮层、异常状态与移动结构。**每轮交付必须同时完成桌面、中间宽度和手机的适用主流程、加载、选择／批量及分页等状态。** 手机单独安排视觉尺寸、布局和触摸范围；不将桌面组件原尺寸照搬到手机，也不将“无横向溢出”单独视为移动适配通过。反馈可以直接引用编号，例如“先做 R01-01”“I07 参数区再紧凑一点”“L13 缺 `Caption` 的筛选改一下”。制作完成后记录实际原型链接与用户反馈；未经用户确认，不把下一层组合或页面记为已通过。

## 全流程验收与下一步

`R16` 按以下用户流程走通模拟交互，并逐条核对 64 项已有确认与适用状态；不是等到最后才第一次检查手机或错误态。

| 编号 | 跨页流程 | 完成证据 |
| --- | --- | --- |
| E-01 | 登录 → 默认任务工作台 → 模块切换 → 项目内页 → 返回／刷新 | 路由、范围与位置恢复正确；两模块和手机四入口持续可达 |
| E-02 | 生产新建／模板 → 组织小节 → 参数／预制编辑 → 生成 → 等待／失败／重试 → 审核／撤销 → 打码 → 导出 | 每步有下一步与失败恢复；任务快照、图片保留、导出阻止及文件路径清楚 |
| E-03 | 生产回收站恢复 → 模板／预制替换 → 归档／彻底删除 | 来源位置与范围不丢失；历史、引用转换、活动阻止与保留内容正确 |
| E-04 | 训练新建 → 档案／参考图 → 构图／输入／生成候选 → 代表图／`Caption` → 训练预览 → `Run` → `checkpoint` 下载／复制 | 不设额外启动门槛；补缺重试、真实取消、单活动训练和独立模型副本清楚；Q-01 未决时不宣称整体完成 |
| E-05 | 训练预制／模板 → 复用构图 → 历史恢复 → 文件清理／归档 | 深复制与持续绑定区别清楚，恢复 `scope` 正确，已清理文件与保留记录可辨 |
| E-06 | 模型缺失 → 影响确认／替换 → 设置保存失败 → `GPU`／ComfyUI 恢复失败 → 日志定位业务对象 | 错误原因、限制、修复入口与原页面返回闭合；不伪装恢复成功 |

当前任务是 **R01-02 层级、手动排序与移动到**，入口为[组织组合](http://127.0.0.1:5178/components/organization/)。`Tree` 定位文件夹，`ListBox` 多选当前内容；“调整顺序”在独立对话框使用原生 `OrderList` 的拖排及顺序按钮，取消不保存、应用后更新；“移动到”对话框选择目标文件夹，当前文件夹不可执行，空文件夹可以接收。桌面与窄屏／手机同轮制作，手机通过文件夹对话框定位；补齐加载、空、失败、只读及焦点返回。全部使用本地模拟数据。

本轮实际检查、限制与用户意见集中在 [R01-02 审核记录](reviews/R01-02.md)，不借用已确认列表或基础页证据宣称本轮已验收。当前组合不包含文件夹创建／删除、跨区域多项拖放或真实业务页面。候选稿完成后仍由用户按场景调整或确认，`C03` 和 `R01` 不随本轮自动完成。
