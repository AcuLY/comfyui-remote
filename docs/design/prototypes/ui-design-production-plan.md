# 生产模块设计任务拆解（R05～R09）

本册把[总路线](ui-design-roadmap.md)中的 `I03`～`I22` 拆成可逐项讨论的用户任务。**全部任务当前均为“拆解草案，待用户确认任务说明”。** 本册不批准任何页面形态，也不是整批开工授权。选中一项后，先确认该项的入口、边界、待决交互和验收范围，再制作这一项的原型；原型仍须另外审核。

2026-09-09 已重新读取本地独立重构检出的 `07-image-production-features.md` 与 `09-forward-compatibility.md`；业务来源沿用总路线固定的 [D7 图片生产决策][d7]、[D9 前向兼容决策][d9]。这些已确认业务能力不因重拆路线而撤销，**业务上有文件夹、排序或多选，不代表必须采用目录树、文件管理器或独立排序弹窗**。`R01-02` 不作为本册任何任务的依赖或获批方案。`C06/C10/C11` 仅标记潜在复用能力，不能先制作通用组合再要求业务页面套用。

## 共同约束与依赖读法

| 项目 | 执行边界 |
| --- | --- |
| 任务粒度 | 一个编号是一项可独立确认的任务说明，不等于一个页面、路由或对话框。多个任务最终可在同一页面完成；这须在相关任务审核时明确 |
| 信息依赖 | 下文依赖的是明确的数据形状、规则或已讨论入口，目的是支持当前决策。可使用这些真实规则构造固定样本，不要求整个前序批次完工；缺哪一项输入只阻塞相关动作 |
| 布局选择 | 卡片、列表、行内展开、侧区、独立工作区等仅可在对应任务中比较。已确认的业务拖放能力保留，落点、排序时机和触屏替代仍需讨论；不预设统一 `Tree`、`ListBox`、`OrderList` |
| 通用验收 | 每项适用主流程、加载、空数据、无筛选结果、局部失败、长名称／路径、提交中与失败保留输入，均纳入桌面、中间宽度与手机的同轮验收；无此场景时记录原因。编辑项补校验及冲突，选择项补取消和范围变化，浮层补焦点返回 |
| 既有基础 | 沿用[基础规范](design-foundations.md)，通过公开组件属性与统一主题配置；不为通过尺寸检查侵入组件内部。紧凑／展开指小节内容呈现偏好，不恢复已取消的控件密度选择 |
| 业务边界 | 本版只有图片小节；统一项目容器不展示视频或类型占位。归档永久只读、无反归档；多选仅属于当前界面会话。历史使用完整目标身份及明确恢复范围，界面显示自然名称 |
| 设计产物 | 每项交付入口定位、可操作流程、适用异常场景、三类视口证据和未解决问题。源代码可运行或检查通过都不等于用户确认 |

## R05：项目定位、创建与小节组织

本批先解释用户如何找到项目、进入小节，再分别讨论创建与组织动作。项目文件夹与小节文件夹是不同范围，不能因名称相似合并成交互模板。`I16` 的项目文件夹和移动能力在本批随真实入口讨论；其余生命周期与复用动作分开列出。

### R05-01 项目浏览与定位

| 字段 | 任务说明 |
| --- | --- |
| 状态／覆盖 | 拆解草案，待用户确认任务说明；`I03` 浏览部分、`C06` 在生产列表中的信息表达；`C08` 最近结果缩略图在本页首次使用时随页设计 |
| 入口与目标 | 从生产模块“项目”入口或返回记录进入，找到目标项目并打开，能判断其是否归档、有活动任务或待审核图片 |
| 包含动作与状态 | 名称搜索、文件夹范围、正常／归档、活动任务与待审条件；展示名称、所属文件夹、最近结果、活动任务数及待审数；最近结果缩略图加载／缺失及适用安全浏览揭示；清除筛选、返回恢复、空目录与无匹配结果 |
| 排除项 | 不制作文件管理器通用组合，不给项目复制一套任务运行状态；新建、移动、删除在后续明确任务中处理 |
| 待确认选择 | 项目信息如何排列；文件夹入口与筛选如何共存；最近结果占多少空间；手机首屏优先展示哪些信息 |
| 信息依赖及原因 | `GEN-PROJ-001/002/015` 的查询语义与项目摘要样本用于比较信息密度；外壳只需给出生产项目入口及返回契约，不依赖整个 R02 |
| 验收结果 | 用同一组样本按名称／文件夹／活动条件定位项目，打开再返回保留范围；归档项目可辨且不误显示编辑入口 |

### R05-02 项目文件夹管理与移动项目

| 字段 | 任务说明 |
| --- | --- |
| 状态／覆盖 | 拆解草案，待用户确认任务说明；`I03` 组织部分、`I16` 项目文件夹与移动部分 |
| 入口与目标 | 在项目列表当前范围内管理文件夹，将一个或多个项目移到明确目标，或删除不再需要的文件夹及内容 |
| 包含动作与状态 | 多级文件夹新建、改名、排序、进入；项目单选／多选、拖入有效文件夹及“移动到”备用入口；非空文件夹删除模态框列出子文件夹和项目数，仅删除全部或取消；提交失败、无效目标与项目非终态任务阻止清理 |
| 排除项 | 不给删除增加“保留内容并移动”分支；不把文件夹移动能力外推为任意资源管理器；不增加未确认的项目手工展示排序 |
| 待确认选择 | 文件夹在项目内容中的位置、排序入口、目标定位方式、多选拖动落点反馈和手机移动操作；确认框中的影响清单展开方式 |
| 信息依赖及原因 | R05-01 的当前位置／返回契约决定动作来源；`GEN-PROJ-003/004` 与 `GEN-LIFE-003` 的数量和阻止项样本决定删除说明；不等待整个生命周期页面完成 |
| 验收结果 | 桌面拖动与键盘／触屏备用入口得到相同目标和数量；取消不移动，失败项可辨；非空文件夹删除前能看懂全部影响 |

| 字段 | 任务说明 |
| --- | --- |

## R06：图片小节编辑及辅助操作

先按参数、提示词、模型来源和恢复范围拆任务。是否组合在同一工作区由真实编辑流程决定；本批不会先批准一个万能编辑器，再让模板和训练套用。

### R06-03 两阶段 LoRA 编辑与来源处理

| 字段 | 任务说明 |

| 验收结果 | 能定位预制／组并管理已确认的组织结构；用户可区别资源顺序、编译顺序与组槽位顺序；未明确的分类删除影响不被模拟成获批行为 |
