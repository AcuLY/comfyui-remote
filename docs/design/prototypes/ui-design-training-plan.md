# 训练界面设计任务拆解

本文是[完整 UI 设计路线](ui-design-roadmap.md)中 `R10`～`R13` 的任务说明草案，覆盖 `L01`～`L19`。业务依据为总路线固定来源 `D8`（训练功能）、`D9`（前向兼容），身份、历史和接口范围按总路线 `D2`／`D3` 对齐；字段冲突沿用总路线 `U-07`，构图代表图使用 `selectedImageId`。本文没有新增业务规则，也没有批准任何页面形态。

## 制作前的规则

下列 **23 个子项均为“拆解草案／待用户确认任务说明”**，没有制作授权。每项先明确入口、用户目的、动作、边界和验收，用户确认范围并要求开始后，再制作对应原型。用户说“继续下一个”时，只能进入已登记且任务说明已确认的下一项；不能临时拆出新编号直接开发。新增或再拆分子项必须先更新此文档和总路线登记，再由用户确认。

任务说明确认只允许制作该范围的设计稿；原型审核、正式前端实现分别记录，不能互相代替。批次顺序是讨论建议，不是要求训练页面继承生产页面或 `R01-02` 目录树交互。`R01-02` 当前暂停方案不作为本文任何子项的前置依赖。

表内“待确认布局”记录该项需要解决的交互问题，不是已选定组件。视觉布局可以在已确认任务范围内探索，不要求制作前拍板所有视觉细节；若问题涉及动作含义、对象或流程边界，先澄清或取得明确探索授权，不能猜测意图开工。除已经确认的项目页签和业务要求的排序能力外，不预先指定目录树、卡片、抽屉或排序弹窗。桌面与手机可以采用不同结构，但必须保留同一任务目标和业务含义。

## 共同验收与依赖口径

每项验收均包含正常、首次空、加载、读取失败与重试；写操作补齐提交中、成功、失败保留输入和适用冲突；项目内写操作补齐归档只读。每轮同时核对桌面、中间宽度、手机、明暗主题、长名称／长文本、键盘焦点与触屏操作；无横向溢出不能单独代表适配完成。选择和排序必须明确作用范围，批量写入展示逐项结果。适用弹出层保留来源上下文并在关闭后返回焦点。

信息依赖只阻止依赖它的具体动作，可以先用明确的模拟字段完成无关部分。基础主题沿用[基础规范](design-foundations.md)；`C` 编号是能力索引。引用 `C05` 导航、`C08` 图片、`C09` 模型、`C11` 历史时，只核对本任务使用的输入与状态，不要求预先制作独立通用组合。图片查看、模型选择和历史在真实消费页面中设计，再评估实际复用。跨子项链接在两端已有原型时补验，不能为补链临时增加未登记业务。

训练页面统一排除：跨项目图片库、角色分析／`Prompt`／`Caption` 任务、训练集版本／冻结实体、候选保留／丢弃审核状态、候选级 `Caption`、多目标／多 `GPU`／多活动训练、训练暂停、唯一最终 `LoRA`、归档恢复及训练产物直接创建预制。正式路径只沿用已确认命名空间与现有明确路径；未确定后缀在任务说明确认时记录，不用旧路由或接口路径代替批准。
