## 后续复用与调整

1. 新业务组合与页面直接复用 `F-01`～`F-14`，先表达业务内容和操作关系。
2. 需要改变基础时，指明受影响的编号与原因，提供实际样本，确认后同步规范、变量和确认记录。
3. 新组件或新页面仍需独立检查两模块、明暗主题、普通与异常状态，以及桌面、中间宽度和手机上的键盘与触摸行为。

后续反馈仍可直接写“F-05 正文改为 15px”或“F-07 保留 36px”。本次确认不取消后续调整，也不把尚未设计或尚未审核的业务组合与页面记为已通过；页面目录、示例文案和模拟业务数据不因此成为业务需求。
