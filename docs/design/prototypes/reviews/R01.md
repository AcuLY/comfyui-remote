用户于 2026-09-08 同意按[全前端设计路线](../ui-design-roadmap.md)开始。**R01-01：列表工具栏、数据表与分页组合**首稿及复制反馈修正已完成，独立复核允许提交用户审核，当前状态为**待用户审核**；实际验证与检查边界见后文。这项工作覆盖 `C03` 的列表部分，并复用 `C01`／`C02`／`C04` 已确认的基础样本；整个 `R01`、`C03` 及后续业务页面均未因此完成或获得确认。

基础视觉沿用已确认的 [F-01～F-14 规范](../design-foundations.md)，不重新调整色相、字体或尺寸。此记录随实际原型、验证结果和用户反馈更新；制作范围、浏览器验证与用户确认是三个独立状态。

| 编号 | 子项 | 原型定位 | 当前状态 |

## 本次制作与审核清单

下表记录已完成首稿的具体候选行为，呈现与交互仍待用户审核。实际验证结果在后文单独填写，不以这份清单代替验证。

| 场景编号 | 内容 | 本次需要展示和检查的行为 |
| --- | --- | --- |
| R01-01-A | 工具栏 | 搜索名称或备注；分类为全部分类／人像／场景／细节；排序为最近更新／最早更新／名称升序／名称降序。结果与计数同步，重置筛选恢复搜索和分类 |
| R01-01-B | 桌面表格 | 名称、分类、备注、更新时间及复制名称操作；普通行与选中行、长名称换行、空备注提示；表头名称／更新时间排序与排序选择器同步 |
| R01-01-C | 选择 | 可单项、多项或本页全选，并可取消；选择仅属于当前页。搜索、分类、排序、页码或每页容量变化均清空选择，工具条明确显示“仅当前页” |
| R01-01-D | 选择工具条 | 显示所选数量，仅演示复制名称和取消选择；复制结果通过视口底部居中的 `Toast` 立即可见。成功显示短提示，浏览器拒绝复制时保留持续提示及明确的手动复制文本入口；不增加删除或其他业务批量动作 |
| R01-01-E | 分页 | 18 条样本，默认每页 5 条，可选 10／20 条；显示当前记录范围与总量。搜索、分类、排序或容量变化回第一页；上一页／下一页及边界按钮状态明确 |
| R01-01-F | 手机卡片 | 760px 及以下从表格转为卡片，保留名称、分类、备注、更新时间、选择和复制名称；业务工具栏始终可见。预览状态与密度收进“预览设置”折叠区 |
| R01-01-G | 内容状态 | 内容、加载、无数据、失败场景；加载保持区域结构，失败有重试；由搜索／筛选自然产生的空结果与初始无数据分开解释 |
| R01-01-H | 主题、模块与密度 | 两模块的强调色与焦点、明暗主题、系统跟随和手动选择、三档密度；沿用已有基础变量 |
| R01-01-I | 键盘与适配 | 搜索、筛选、排序、选择和分页的可见焦点及键盘可用性；桌面、中间宽度、手机与触摸目标；减少动态效果偏好 |

此次列表排序是按字段改变展示顺序，不包含拖放、树层级或手动资源顺序的设计。列表进入真实业务页面后，还需按该页面补齐业务列、适用动作及返回上下文，不能直接用通用样本批准整页。
