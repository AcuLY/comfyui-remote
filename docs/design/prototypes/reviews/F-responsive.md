# 响应式适配审核

用户于 2026-09-08 要求**非必要不侵入组件库**：撤回人工整圈焦点及数字组件的非必要特殊覆盖，恢复组件库原生结构。本记录保留该要求与验证口径，具体尺寸与色值属视觉风格内容，不在本契约维护。

## 原生结构原则

| 修订项 | 规则 |
| --- | --- |
| 原生结构 | 使用组件库公开属性表达布局与状态，不重排库内部按钮 |
| 焦点 | 不模拟父容器焦点，沿用组件库原生焦点形状 |
| 内部样式 | 撤去只为像素对齐的内部覆盖；主题定制放入公开主题入口，让库内部结构规则优先 |
| 点击与内边距 | 不添加透明点击层、隐藏输入偏移或手动根点击聚焦 |
| 保留项 | 公开属性可表达的功能与无障碍名称必须保留 |

## 多视口与输入验证口径

- 检查桌面、手机与一个中间宽度，覆盖两模块、深浅主题和关键交互状态；断点检查覆盖临界两侧。
- 真实触控目标、边缘命中、相邻对齐和键盘焦点必须实测，不能仅凭样式声明或无横向溢出认定通过。
- 手机布局不使用悬停底色，保留按下、选中和键盘焦点；鼠标桌面保留悬停。缩窄浏览器不等于真机触摸验证，未覆盖真机或读屏时明确写出限制。
- 浮层（下拉、弹窗、轻提示）继承页面主题与模块上下文，背景滚动锁定与关闭后焦点返回需要验证。
