# R01-02 层级、手动排序与移动到审核记录

## 当前范围与状态

用户于2026-09-09指出本子项的通用定位不适用于多数业务，并质疑其在原任务文档未明确时被临时拆出。**当前状态：定位偏差，暂停制作。** 用户随后要求先拆清设计文档，任何子项必须事前登记做什么、范围和验收；新约束见[总路线](../ui-design-roadmap.md)。此前代理提出“收窄成模型管理样本”只是建议，尚未成为用户确认的替代任务，不自动改名、迁移或作为模型页面批准。

以下保留当时做过的组件、快照和验证，是历史实现记录，不再作为通用组件复用约束，也不提供继续开发授权。

原型入口为 `components/organization/index.html`，浏览器路径为[层级、手动排序与移动到](http://127.0.0.1:5178/components/organization/)。页面优先读取一次生成的本机目录快照，没有快照时回退内置模拟数据；刷新恢复快照初始状态。原型不调用真实文件移动、业务接口、数据库或任务队列。

## 组件职责与交互边界

沿用[基础规范](../design-foundations.md)与[统一主题](F-theme.md)：桌面普通控件 36px，手机／粗指针普通控件 40px、可编辑输入字号 16px，纯图标动作 44px。组件的内部结构、焦点及状态由官方主题和公开属性管理；页面样式负责外层布局，不新增透明热区或内部标签、隐藏输入补丁。

| 编号 | 组件与用途 | 组合规则 |
| --- | --- | --- |
| R01-02-01 | `Tree`：文件夹定位 | 整行点击选择并展开／收起，箭头保留原生展开行为；手机父目录保持对话框打开以便继续定位，使用“查看此文件夹”确认返回，叶目录选择后直接返回 |
| R01-02-02 | `ListBox`：当前内容多选 | 通过公开受控选择管理移动操作的对象；选择属于当前文件夹，切换文件夹后清空，不把其他文件夹的隐藏选择带入动作 |
| R01-02-03 | `OrderList`：调整当前文件夹顺序 | 在“调整顺序”对话框中使用库原生拖排、上移／下移／移至首位／移至末位按钮；取消不保存，应用后更新当前文件夹。排序对话框内部选中项与移动选择相互独立 |
| R01-02-04 | `Dialog` 与 `Tree`：移动到 | 显示所选数量与来源，选择目标后明确确认；当前文件夹不可执行移动，空文件夹可接收；取消保留原内容 |
| R01-02-05 | `Skeleton`、消息与 `Toast` | 加载保留文件夹／内容区域结构；空、失败、只读分别解释原因和可用动作；排序或移动完成后提供结果反馈 |

`PrimeReact 10.9.9` 的 `OrderList` 没有用于业务选择的受控 `selection`／`onSelectionChange` 入口，因此不读取其内部状态或通过组件私有结构驱动移动工具条。当前内容多选与排序编辑采用两个职责明确的原生组件，通过确认动作衔接。

本子项验证同一文件夹内的原生拖排及顺序按钮替代，不据此宣称已实现跨区域多项拖放。文件夹创建、删除、文件夹本身的移动、真实项目／小节／模板业务规则均留到对应页面；不能从本地模拟成功推导真实接口成功或权限语义。

## 整行点击与本机目录快照（后续修订）

按用户反馈，目录行通过公开 `onNodeClick` 与受控 `expandedKeys` 实现整行展开／收起；原生箭头阻止冒泡，不会触发两次切换。导航树、手机目录对话框及移动目标树使用相同规则，移动提交中不响应展开操作。没有增加透明点击层或覆盖内部结构。

按新版设计 `IP-02 / MODEL-001` 及本地目标配置核对来源后，本轮读取一次真实 `models` 根目录，得到100个文件夹、506个文件，跳过0项。只保存文件元数据，模型内容未读取；快照放在忽略的 `public/local-mocks/organization.json`，不会提交。没有本机快照的检出仍可使用内置数据。默认打开有内容的 `checkpoints`，树和列表使用有界滚动容器承载真实目录数量。

本轮实点桌面根目录行右侧空白：收起后剩1个可见目录，再次点击展开为52个；手机同样可从整行收起，父目录选择后对话框保持打开，“查看此文件夹”可返回内容。393px对话框内容无横向溢出，普通输入仍为40px；当前初始目录的8个文件和快照来源计数已在页面核对。先前使用内置样本的验证保留为历史，不视为真实文件移动验证。

## 本轮审核场景

以下为制作及验收清单，实际结果须在下一节记录；列出场景不等于已通过。

| 场景编号 | 内容 | 需要展示和检查的行为 |
| --- | --- | --- |
| R01-02-A | 层级定位 | 多层文件夹展开、折叠与选择；当前位置清楚，长名称可读；切换文件夹显示其内容并清空旧选择 |
| R01-02-B | 当前内容选择 | 单项、多项、取消选择；所选数量与动作状态同步；未选时不能执行移动，排序编辑与移动选择不相互污染 |
| R01-02-C | 手动顺序 | 打开调整顺序对话框，原生拖排与顺序按钮可改变临时顺序；无选中时顺序按钮禁用，首尾不越界；取消不落地，应用后当前内容采用新顺序 |
| R01-02-D | 移动到 | 对话框显示来源与数量，目标树可展开和定位；当前文件夹不可执行，空文件夹可选；取消无变更，确认后来源与目标内容数量同步并有反馈 |
| R01-02-E | 手机与窄屏 | 文件夹对话框替代挤压的并列树；定位、内容多选、顺序按钮、目标选择和确认始终可达；长名称、短横屏与中间宽度各自复核，不只检查溢出 |
| R01-02-F | 加载与空状态 | 文件夹和内容加载有相应骨架；空文件夹自然空状态与预览无数据状态可辨；空目录排序不可执行，不显示选择移动工具条 |
| R01-02-G | 失败与只读 | 加载失败可重试；只读保留浏览与层级定位，禁止排序与移动并解释原因；切换预览状态不会意外提交未应用顺序 |
| R01-02-H | 主题与尺寸 | 生产／训练、浅／深色沿用共用偏好；标准密度固定，桌面 36px、触控普通控件 40px、图标动作 44px；短控制组有宽度上限 |
| R01-02-I | 键盘、焦点与反馈 | 文件夹展开／选择、内容选择、顺序按钮和对话框可由键盘操作；对话框焦点约束、退出键及关闭后返回触发器；提示在手机视口可见，减少动态效果保留语义 |

## 本轮验证记录

本节记录本轮实际检查，不继承 `R01-01`、基础页或历史截图的通过结论。浏览器强制视口截图仍有缩放失真，响应式结论来自实际布局读数和交互，不声明真机或读屏验收。

| 检查项 | 实际证据与限制 | 结果 |
| --- | --- | --- |
| 桌面、中间宽度、手机与短横屏 | 320／393／768／959／960／1280／2560px 无页面横向溢出，960px 起并列目录树，窄屏使用文件夹对话框。手机输入40px、顺序按钮44px；768px及桌面精细指针输入36px。393px排序按钮原生横排；320px文件夹对话框内容不横向溢出；852×393排序对话框完整位于视口，底部动作可见 | 指定布局通过 |
| 文件夹定位与当前内容选择 | 手机及桌面目录选择更新当前位置；两项内容多选显示正确数量，换目录清选；过滤计数复用 `FilterService`，跨字段关键词“像 柔”为空结果并显示0项 | 指定操作通过 |
| 手动顺序 | 原生上移将“窗边阅读”置于“晨光人像”前，应用后主列表更新；再次下移后取消，主列表顺序保持。原生拖放已接入，浏览器工具两种鼠标拖动方式均未触发重排，拖动拦截接口不受支持 | 按钮替代路径通过；实际拖放仍待人工复核 |
| 移动到 | 未选不能移动，当前文件夹确认禁用；两项移动到空“待整理”后目标显示两项且保留原顺序。下一次失败模拟保留来源、目标和选择，直接重试后成功；失败不写入模拟数据 | 指定操作通过 |
| 加载、空、失败、只读 | 加载态有22个文件夹／内容骨架并标记忙碌；自然空文件夹、无数据返回样本和加载失败重试均可操作。只读仍可检索和浏览，选择变更被阻止，排序禁用，移动工具条不显示 | 指定状态通过 |
| 主题、键盘与焦点 | 已检查深色生产与浅色训练；320px文件夹对话框反向制表键保持内部焦点，退出键关闭后回到“文件夹”按钮；减少动态效果下骨架动画为 `0.01ms`，测试后恢复媒体设置 | 所测主题与焦点路径通过；完整读屏及拖放键盘对照未测 |
| 原型构建与文档门禁 | 原型构建、19项产品设计治理测试及完整文档检查通过；文档零错误、零警告 | 通过 |
| 用户审核 | 用户指出任务定位偏差，先重拆路线；未认可通用方案或模型页转用 | 暂停 |

本机证据目录为 `.impeccable/review/r01-02/`，保存桌面截图和视口读数，不跟踪提交。所测场景控制台无警告或错误。

源码独立复核发现并修正两个问题：手写匹配数与组件过滤规则不一致、只读态误禁用搜索与键盘浏览。组件继续使用公开接口；原生排序布局依赖的 `--primary-color`、`--content-padding`、`--inline-spacing` 在主题变量层映射，未覆盖内部结构。搜索字段通过公开过滤容器槽位限宽400px，宽屏不会随内容面板无限拉长。
