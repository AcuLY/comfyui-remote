# R02-02 项目上下文与导航恢复

## 开始依据与范围

用户于2026-09-12要求“基于整理的规则继续设计下一个原型”，本轮执行此前已登记的 `R02-02`，不新增子项。按既有顺序继续制作不追溯为 `R02-01` 全部设计已获批准；本项完成后单独交用户审核。

用户目的：从项目或任务来源进入项目，在项目内部切换视图，返回时保留原范围；刷新、浏览器前后和失效目标均有可预期的落点。

本项是已有导航外壳的扩展。首稿把项目与任务来源简化成了同一类项目记录，缺少图片与文件夹上下文，用户于2026-09-12指出功能和 UI/UX 理解偏差，并要求先对照旧前端与设计演示。随后明确：各类卡片应展示图片，能双列时优先双列，补上文件夹操作。本次在既有 `R02-02` 内登记并修正这些导航样本，不临时拆出任务号。

导航样本必须保留项目、小节／构图与独立任务之间的真实关系。补充生产项目及生产小节的文件夹进入、路径返回、新建、改名与移动到；卡片使用明确归属的静态样本图片，无图时展示真实空态。全部修改只作用于原型的本地会话模拟数据，不调用业务写接口，也不修改真实项目、文件夹或图片。参数编辑、生成／训练执行、完整图片审核及素材编辑仍留在既有业务任务中。

## 当前契约

| 事项 | 规则与来源 |
| --- | --- |
| 生产项目页签 | 概览、小节、图片、任务，来源 `IA-07 / N-03` |
| 训练项目页签 | 概览、角色档案、参考图、构图、训练素材、任务，来源 `IA-08 / N-04` |
| 内容卡片与图片 | 项目卡以最近结果为视觉入口；生产小节／训练构图卡展示自身候选或代表图；图片任务卡优先展示该次输出，训练运行的样本图明确标为本次训练样本。尚无输出的任务卡可展示来源图，必须标注“来源参考 · 尚无输出”，不能将参考图冒充输出；没有任何可展示图片才使用卡内空态。任务详情的输出区在无输出时始终显示空态。示例图片只证明展示与归属关系，不代表真实生产数据 |
| 响应式卡片布局 | 内容区可容纳两列时优先两列，以实际可用内容宽度判断，不只依赖视口宽度。当前实现目标为内容宽度至少344px时两列；320px视口使用单列。需检查长名称、状态与操作入口，不能以文字截断或不可点击换取双列 |
| 项目与任务身份 | 项目列表展示项目；任务列表展示有自身身份、状态和所属项目的独立任务。图片任务关联来源生产小节／训练构图，并提供所属项目与小节／构图跳转；项目级训练运行不得伪造单一构图归属，来源 `ARCH-007 / TRN-RUN-001～003` |
| 文件夹适用范围 | 文件夹仅在已确认的生产项目列表和生产项目内小节列表中出现；两套文件夹身份和范围互不混用。训练项目／构图按各自排序组织，任务按任务筛选／分组组织，不新增训练或任务文件夹，来源 `GEN-PROJ-003 / GEN-SEC-007 / ARCH-003 / LTD-01 / LTD-05` |
| 文件夹操作 | 进入多级文件夹、逐级路径返回、在当前层新建／改名、将项目或同项目生产小节移动到目标文件夹／根目录。显示当前范围和操作结果，取消不改状态；移动目的地不得来自另一对象范围，来源 `GEN-PROJ-003～004 / GEN-SEC-007`。本次使用“移动到”验证触屏与键盘路径；完整拖放、多选、排序及删除流程不在本次导航样本中宣称完成 |
| 层级与来源 | 面包屑表达模块／项目／小节或构图层级；“返回项目列表”或“返回任务列表”表达实际来源，二者不混用，来源 `IA-11 / FC-16` |
| 可分享内容 | 当前项目／页签／深层样本和列表筛选写入原型片段；本轮的路径形式不是获批业务地址，来源 `IA-11 / Q-03` |
| 恢复范围 | 每个地址保存滚动位置，返回、刷新和浏览器前后恢复；搜索、状态筛选及文件夹范围随地址恢复。文件夹内进入项目或小节再返回，应回到原文件夹及对应卡片，并恢复焦点。首稿的导航摘要已取消，当前没有摘要展开及其恢复状态，来源 `IA-12 / PLAT-006 / V-12` |
| 无来源深链 | 可直接打开项目，返回同模块项目列表，不依赖访问者浏览器中可能无关的上一页 |
| 失效目标 | 无效页签回项目概览；无效小节／构图回所属项目的对应页签；无效项目回同模块项目列表；无已知父级才回应用入口，来源 `COMPAT-006 / API-16` |
| 模块切换 | 沿用最新 `R02-01` 规则：点击模块轨道进入对应任务，不能恢复旧模块项目；更多中切换保持面板打开 |
| 主题与外壳 | 复用现有侧栏、底栏、更多、主题及动画；默认跟随系统，选相反颜色固定、选回系统当前色恢复跟随 |
| 训练边界 | 保留新版六页签和构图／代表图／说明文本关系，不恢复旧版 `DatasetRevision`、`DatasetVersion`、候选图 `reviewStatus` 或虚构冻结流程，来源 `LTD-05 / LTD-12 / LTD-18 / TRN-PROJ-003` |

源设计位于本地重构检出的 `openspec/changes/rebuild-application/decisions/02-domain-models.md`、`04-design-and-components.md`、`06-platform-features.md`、`07-image-production-features.md`、`08-lora-training-features.md` 与 `09-forward-compatibility.md`；对应固定版本链接由[总路线](../ui-design-roadmap.md#输入来源与更新边界)维护。本轮只读取这些来源。旧前端与设计演示用于理解业务对象及操作顺序，不能覆盖新版明确移除的功能。

静态照片来源与用途记录在本原型的[图片来源清单](../public/media/context/SOURCES.txt)。这些公开图库照片及其项目关联均为模拟内容，不是用户图片、真实生成结果或训练素材。

## 组件与应用职责

| 层次 | 实现选择 | 验证责任 |
| --- | --- | --- |
| 全局外壳 | 从 `R02-01` 提取同一可复用外壳；原独立页面继续可用 | 入口顺序、更多关闭规则、主题与侧栏收放不回退 |
| 项目层级 | 原生 `BreadCrumb`、带真实地址的返回链接 | 长项目名、小屏可读、层级返回与来源返回不同且明确 |
| 项目页签 | 原生 `TabMenu`，受控当前页签 | 生产四项与训练六项不混用；手机完整可达；键盘、地址及内容身份同步 |
| 来源样本 | 原生输入、下拉、按钮与包含图片的项目／小节／构图／任务卡片 | 图片与所属对象一致，主要导航和操作菜单命中区不冲突；双列下仍可读可操作；任务不复用项目记录 |
| 文件夹与移动 | 生产范围内的文件夹入口、路径面包屑、原生菜单／对话框／表单控件 | 进入、返回、新建、改名、移动／取消形成完整本地交互；项目与小节目标范围隔离；不侵入组件库内部样式 |
| 恢复逻辑 | 原型独立会话记录及浏览器历史 | 地址、筛选、文件夹范围、滚动与焦点交接由应用负责，不能只验证选中样式 |

宽屏在外壳内容区呈现图片卡片与项目导航；手机顶部用于项目名称、返回、文件夹范围和当前页签，保留既有底栏。卡片按内容宽度优先双列，极窄屏退为单列；长名称允许换行，操作入口不能挤出卡片。训练六页签在小屏完整排列，不依赖只露出部分文字的横向滚动才能发现后续入口。

## 本轮验收

1. 各类内容卡展示所属对象的图片；没有图片的样本显示明确空态。320px单列、393px及中间视口可用内容宽度足够时双列，图片、长名称与操作均完整可用。
2. 生产项目文件夹与项目内小节文件夹均可进入及逐级返回；新建／改名有可见结果，取消不改状态；移动项目／小节后在目标范围可找到原对象，刷新保留本地会话结果。
3. 从文件夹范围搜索／筛选并进入项目及小节；切页签、刷新、返回列表后恢复原文件夹、查询与位置，不串用另一模块或另一项目的文件夹。
4. 任务来源使用独立任务，可进入该任务并跳到所属项目／小节或构图；项目级训练运行只显示真实项目归属。返回任务来源保留查询和位置，六个训练页签身份正确。
5. 项目页签和深层地址刷新后仍可定位；浏览器前后与界面返回均可用。无效页签、小节／构图、项目及文件夹回最近有效父级，有就地说明且不跨模块。
6. 桌面、手机和中间视口，键盘焦点、对话框取消及返回位置符合以上行为；主题与共享外壳做针对性回归。

本轮已修订并完成以下针对性验证，待用户审核。以下结果仅记录本轮实际操作，不沿用首稿通过结果，也不代表所有状态与视口组合均已验证：

| 检查 | 本轮结果 |
| --- | --- |
| 图片、长名称与双列适配 | 393px、623px及1280px为双列，320px为单列；623px无横向溢出，新增长名称自然完整换行；所测图片加载失败数为0；失败任务详情明确显示无输出图片 |
| 生产项目／小节文件夹与移动操作 | 完成“新建文件夹→改名→移动项目→进入目标→刷新”，项目仍位于目标文件夹；小节成功移入两层嵌套文件夹；393px下按 `Esc` 取消新建后未新增文件夹 |
| 独立任务与所属对象跳转 | 完成“小节列表→小节→独立任务→返回小节→小节列表→原项目列表”的连续路径；任务列表搜索“雨后”后进入失败任务，再进入所属项目，返回任务的链接仍保留原查询 |
| 文件夹范围、查询与焦点恢复 | 上述连续路径返回后，原文件夹范围、查询和对应卡片焦点准确保留；在嵌套小节文件夹中切到任务页签，再切回小节，恢复原文件夹；失效文件夹回根目录并提示。未逐一复测全部浏览器历史、滚动恢复和失效目标组合 |
| 主题、共享外壳与键盘 | 手机更多面板内切换训练模块后面板保持打开，浅色主题及训练粉色正确；320px训练六页签可通过 `Enter` 导航。未逐一复测全部键盘及深色组合 |
| 构建、模型及文档检查 | 原型构建通过；20项模型测试及29项治理测试通过；文档检查0错误、3条未提供比较基线时产生的语义提醒。本轮仅修改原型和相关文档，未改业务接口或执行器，设计记录已同步 |
