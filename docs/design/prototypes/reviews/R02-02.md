# R02-02 项目上下文与导航恢复

## 开始依据与范围

用户于2026-09-12要求“基于整理的规则继续设计下一个原型”，本轮执行此前已登记的 `R02-02`，不新增子项。按既有顺序继续制作不追溯为 `R02-01` 全部设计已获批准；本项完成后单独交用户审核。

用户目的：从项目或任务来源进入项目，在项目内部切换视图，返回时保留原范围；刷新、浏览器前后和失效目标均有可预期的落点。

本项是已有导航外壳的扩展。项目／任务列表只用少量导航样本验证搜索、状态筛选、展开与滚动；项目概览、参数编辑、图片／素材、执行任务和业务接口均不制作，不读取真实生产数据。

## 当前契约

| 事项 | 规则与来源 |
| --- | --- |
| 生产项目页签 | 概览、小节、图片、任务，来源 `IA-07 / N-03` |
| 训练项目页签 | 概览、角色档案、参考图、构图、训练素材、任务，来源 `IA-08 / N-04` |
| 层级与来源 | 面包屑表达模块／项目／小节或构图层级；“返回项目列表”或“返回任务列表”表达实际来源，二者不混用，来源 `IA-11 / FC-16` |
| 可分享内容 | 当前项目／页签／深层样本和列表筛选写入原型片段；本轮的路径形式不是获批业务地址，来源 `IA-11 / Q-03` |
| 恢复范围 | 按同模块资源身份保存展开状态；每个地址保存滚动位置，返回、刷新和浏览器前后恢复；搜索与状态筛选随地址恢复，来源 `IA-12 / PLAT-006 / V-12` |
| 无来源深链 | 可直接打开项目，返回同模块项目列表，不依赖访问者浏览器中可能无关的上一页 |
| 失效目标 | 无效页签回项目概览；无效小节／构图回所属项目的对应页签；无效项目回同模块项目列表；无已知父级才回应用入口，来源 `COMPAT-006 / API-16` |
| 模块切换 | 沿用最新 `R02-01` 规则：点击模块轨道进入对应任务，不能恢复旧模块项目；更多中切换保持面板打开 |
| 主题与外壳 | 复用现有侧栏、底栏、更多、主题及动画；默认跟随系统，选相反颜色固定、选回系统当前色恢复跟随 |

源设计位于本地重构检出的 `openspec/changes/rebuild-application/decisions/04-design-and-components.md`、`06-platform-features.md` 与 `09-forward-compatibility.md`；对应固定版本链接由[总路线](../ui-design-roadmap.md#输入来源与更新边界)维护。本轮只读取这些来源。

## 组件与应用职责

| 层次 | 实现选择 | 验证责任 |
| --- | --- | --- |
| 全局外壳 | 从 `R02-01` 提取同一可复用外壳；原独立页面继续可用 | 入口顺序、更多关闭规则、主题与侧栏收放不回退 |
| 项目层级 | 原生 `BreadCrumb`、带真实地址的返回链接 | 长项目名、小屏可读、层级返回与来源返回不同且明确 |
| 项目页签 | 原生 `TabMenu`，受控当前页签 | 生产四项与训练六项不混用；手机完整可达；键盘、地址及内容身份同步 |
| 来源样本 | 原生输入、下拉、按钮与简单列表 | 只展示恢复所需字段，检查真实点击范围，不扩展业务列表需求 |
| 恢复逻辑 | 原型独立会话记录及浏览器历史 | 地址、筛选、展开、滚动与焦点交接由应用负责，不能只验证选中样式 |

宽屏在外壳内容区呈现来源列表与项目导航；手机顶部用于项目名称、返回和当前页签，保留既有底栏。长名称允许换行；训练六页签在小屏完整排列，不依赖只露出部分文字的横向滚动才能发现后续入口。

## 本轮验收

1. 生产列表搜索／筛选并展开一项，滚动后进入项目及小节；切页签、返回列表后恢复原范围与位置。
2. 训练从任务来源进入项目，六页签身份正确；返回任务来源保留查询和位置。
3. 项目页签和深层地址刷新后仍可定位；浏览器前后与界面返回均可用。
4. 无效页签、小节／构图、项目分别回最近有效父级，有就地说明且不错误跳到另一模块。
5. 桌面、手机和中间视口，键盘焦点及返回位置符合以上行为；主题与共享外壳做针对性回归。

首稿已制作，待用户审核。实际验证如下：

| 检查 | 结果 |
| --- | --- |
| 生产项目来源恢复 | 进行中筛选、暖色厨房摘要展开、约635px滚动后进入项目及小节；深链刷新后返回，筛选／展开／滚动与原项目链接焦点均恢复 |
| 训练任务来源与页签 | 搜索“角色”后进入长名称项目；返回任务来源保留查询及链接焦点；六页签在320px完整显示、各44px高，方向键及回车同步片段 |
| 历史与层级 | 项目页签前进／后退正确；小节和构图深链刷新可定位，面包屑可返回项目；无来源地址默认返回同模块项目列表 |
| 失效目标 | 无效页签回项目概览、无效构图回项目构图、无效项目回训练项目列表；均有说明，未跨模块回生产 |
| 视口与主题 | 320、393、623、1024px及640×360短横屏无横向溢出；桌面与手机长标题、项目页签、浅／深及两模块组合做了代表性检查 |
| 外壳复用回归 | R02-01独立入口可用；收起与模块切换、手机更多内切换保持打开的行为未回退 |
| 工程检查 | 原型构建、11项纯模型测试通过；机械检测无报告项；浏览器所测控制台无错误或警告 |

这些结果只覆盖当前静态导航样本，不代表业务页面、真实数据、鉴权或真机触控验收。原型视口截图在宿主可能缩放失真，尺寸结论以浏览器布局读数为准。
