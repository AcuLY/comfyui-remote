# 生产模块重做：演示结构与新版组件

2026-09-14 用户要求放弃当时的项目和任务方案，任务和项目以设计演示为主要参考，预制和模板以旧前端为主要参考。本记录保留功能结构与组件契约，具体视觉风格内容已去除。

## 参考与实现范围

| 区域 | 优先参考 | 本轮结构及操作 |
| --- | --- | --- |
| 任务工作台与运行审核 | 设计演示的队列与审核页 | 当前运行进度、按项目分组的待审内容；队列批选与暂停／恢复／取消／重试；运行快照、用途标记、连续审核 |
| 项目列表与文件夹 | 设计演示的项目列表与旧项目实现 | 标题和数量同排、最近结果缩略图、紧凑状态操作；选择、移动、排序、创建编辑 |
| 项目与小节 | 项目详情与小节卡片 | 小节／结果视图、右侧小节导航；参数、预制、提示词、`LoRA`、历史与结果平级编辑；所选／全部生成 |
| 图片与交付 | 运行审核与旧打码、导出实现 | 多选及用途标记、单图打码、批量打码、导出范围、归档／删除影响确认 |
| 预制与组 | 旧前端预制页 | 分类、路径与行式条目；槽位、变体、正负提示词、成员、历史与排序 |
| 模板 | 旧前端模板页 | 紧凑模板列表与编辑；默认参数、绑定、提示词、`LoRA`；导入项目与另存 |

参考业务结构和操作顺序，不复制旧组件实现、过小触控区域和装饰样式。与已确认业务规则冲突的旧行为不恢复：归档永久只读；新建项目在同一表单选择模板；小节支持所选／全部生成。

## 组件与适配契约

沿用 `PrimeReact` `10.9.9` `Styled` 与统一主题。优先使用库提供的 `TabMenu`、`SelectButton`、`Dropdown`、`Dialog`、`Menu`、`Checkbox`、`InputNumber`、`ProgressBar` 等公开入口；应用负责路由、数据变更、业务拖拽和来源关系。**不得通过内部 `CSS` 选择器重新实现组件行为。**

信息密度来自合并冗余行、缩略图带和清楚的操作分组，不靠缩小触控范围。窄屏将辅助侧栏移入明确触发的面板或折叠区域，页面顶部保留业务操作，底部继续使用已实现的导航。标题、输入及按钮不截断关键内容。

跨页面使用同一份项目、小节、任务、图片、预制和模板数据。创建任务进入队列；图片审核同步项目结果；导入／另存模板真正改变本地结构；取消不提交。等待和执行只作明确的演示模拟，不伪装真实生成。
