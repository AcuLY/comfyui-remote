# R02-01 全局导航外壳审核记录

## 事前登记与当前状态

本项已在[共享任务计划](../ui-design-shared-plan.md#r02-导航与登录)事前登记，属于 `R02`、覆盖 `C05`。用户于2026-09-09核对 `R01-01` 已确认、`R01-02` 暂停后，要求“先继续设计计划的下一项”；本轮据此选定既有 `R02-01`，没有新拆子项。本文先记录制作范围，再开始界面制作。**首稿已制作，待用户审核**；用户继续指令不是对具体布局成稿、全部79项或后续任务的批准。

用户目的：首次进入应用时到达生产任务；在生产／训练各四个一级入口和全局工具间切换，始终辨认当前模块与位置。`R01-02` 继续暂停，不作为本项输入。

## 输入、确定事项与本轮探索

业务来源是[总路线的D4输入](../ui-design-roadmap.md#输入来源与更新边界)，已重新读取本地重构检出的信息架构决策 `IA-01`～`IA-06`、`IA-16`。这些规定已经确定导航区域，不把本轮当作重新选择信息架构。

| 输入 | 已确定事项 | 本轮呈现与边界 |
| --- | --- | --- |
| IA-01 | 首次／无有效记录进入生产任务，根入口恢复有效位置 | 用导航占位实现首次入口与有效顶层位置恢复；无效片段回退生产任务，不制作项目资源失效流程 |
| IA-02/03 | 生产／训练同权、始终可见；各自项目、任务、预制、模板四入口 | 设计活动项、模块切换与入口级最后位置记忆，不隐藏训练或任务 |
| IA-04/05 | 桌面侧栏顶部模块切换、中部四入口、底部全局模型、监控与日志、设置及注销；内容预留空间 | 设计展开／收起的宽度、标签与当前定位；具体呈现是本轮候选，未获用户批准 |
| IA-06 | 手机顶部模块切换、底部四入口，全局工具与注销在明确“更多”中 | 设计窄屏衔接与更多菜单，不沿用桌面同尺寸侧栏挤占手机内容 |
| IA-16 | 当前项不只靠颜色，支持键盘、跳至主内容、减少动态效果及浏览器返回 | 当前入口同时具备文字／图标与状态；使用简单片段导航验证前后行为 |
| 已确认基础 | 统一主题、字体、密度、模块色、纯白浅色底与系统主题跟随 | 沿用共享提供器与公开组件接口，只增加导航外层布局 |

## 本轮包含与排除

| 范围 | 本轮做什么 | 不做什么 |
| --- | --- | --- |
| 一级导航 | 生产／训练四入口切换、各模块记住最后入口、桌面收放、手机底栏 | 不设计项目页签、面包屑或项目操作；这些归R02-02 |
| 全局工具 | 模型、监控与日志、设置入口，以及手机更多的打开／关闭与当前定位 | 不制作模型文件列表、设置表单、监控数据、日志列表或业务接口 |
| 路由验证 | 用原型片段区分顶层入口；浏览器前后与刷新可回同一占位 | 片段不是获批业务路由；查询、展开、页签、滚动和失效资源恢复归R02-02 |
| 注销 | 展示入口并反馈“原型演示，未退出真实登录”等非真实结果 | 不读取令牌、不清除真实认证、不绘制登录过程；鉴权归R02-03 |
| 内容区域 | 清楚标注的占位，只给页面名称和导航定位信息 | 不以虚构业务表格、指标或卡片冒充页面已设计，不加概览仪表盘 |
| 适配与状态 | 桌面、窄屏、手机导航；当前项、收放、菜单、焦点及减少动态效果 | 不要求纯导航占位假装具备业务加载、错误、空列表或批量状态 |

原型目标：`shell/navigation/index.html`，源码 `src/navigation.jsx`、`src/navigation.css`，预览地址为[全局导航外壳](http://127.0.0.1:5178/shell/navigation/)。这些是原型文件与预览地址，不是正式应用路由。

## 验收与实际验证

| 应检查的结果 | 实际结果 |
| --- | --- |
| 首次进入生产任务，跨模块返回其最后入口，全局工具保持独立身份 | 首次状态回到生产任务；生产预制→训练模板→生产，回到生产预制；全局模型／设置有独立当前项，手机底栏不误选业务项 |
| 桌面展开／收起不遮挡内容；窄屏仍能定位当前入口 | 1200px起默认展开232px；768～1199px默认80px窄栏，图标链接保留名称与提示。触屏窄栏用88px，生产／训练两字不换行、按钮40px；已验证手工收放与内容留位 |
| 手机顶部两模块与底部四入口均可达，更多包含全局工具和注销 | 320／393／640px保留顶部两模块和底部四链接；模块按钮40px、更多图标44px。852×393粗指针横屏采用手机结构。模型、监控与日志、设置及注销均在更多中；注销只产生预览提示，片段不变 |
| 浏览器前后、刷新与无效片段回退正确；不声称已实现项目恢复 | 后退回训练模板，前进／刷新恢复生产预制；无效片段回到生产任务。本项只保存顶层入口，不存项目查询／滚动状态 |
| 键盘焦点、跳至内容、菜单退出及当前项语义正确 | 跳到主内容聚焦 `navigation-main` 且不改变片段；更多内反向制表键到退出入口，退出键和遮罩可关闭并回到更多按钮。首次使用的侧栏缺少焦点约束，已改为 `Dialog` 的右侧模态呈现；侧栏收放控制目标也已更正；减少动态效果下收放过渡为 `0.01ms`，检查后恢复媒体设置 |
| 深浅主题及两模块颜色、适用视口无横向溢出 | 已切换浅／深与生产／训练四组合，浅色画布纯白、深色画布中性灰；320、393、640、768、960、1199、1200、1440、2560px均无页面横向溢出。所测控制台无警告或错误 |
| 原型构建、设计治理测试与文档检查 | 原型构建、19项设计治理测试和完整文档检查通过；文档零错误、零警告 |

本轮证据目录为本机 `.impeccable/review/r02-01/`，不跟踪提交。响应式结论来自实际布局读数与交互；强制视口截图在当前宿主有缩放失真，不视为真机像素验收。没有验证真实业务数据、鉴权或项目级恢复，也不沿用 `R01` 的检查代替本项。

原生链接承载片段导航，模块切换、收放、预览设置沿用 `Button`／`SelectButton`／`Dialog`。导航外层样式不修改组件库内部结构；本轮侧栏宽度和导航定位仍是候选呈现，需用户审核。

## 后续修订：收起侧栏的模块图标

用户要求将窄栏中的生产／训练文字改为图标。收起侧栏使用 `PrimeIcons` 的图片图标与训练芯片图标，直接通过 `Button` 的 `icon` 属性呈现，保留完整名称的无障碍标签、悬停提示和按下状态；展开侧栏及手机顶部仍用文字。961px窄栏实测两按钮均为36×36px，模块切换正常；展开侧栏后恢复文字。此修订替代上方收起状态的文字按钮描述，旧尺寸记录保留为历史。仅调整本项局部呈现，不扩大任务范围。

用户随后要求轨道样式：收起侧栏时两个图标位于同一条竖向圆角轨道，内边距4px，选中项使用原生圆形按钮高亮。通过外层布局与 `Button rounded` 公开属性实现，不绘制额外焦点层或修改内部图标；展开侧栏和手机顶部保持文字切换。
