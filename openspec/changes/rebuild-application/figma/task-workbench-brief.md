# 图像生产任务工作台：首稿设计说明

状态：待设计审核。关联 IA-01～IA-16、VD-01～VD-14、CA-01～CA-14、ARCH-006/010、GEN-RUN-001/003/005/007/008、IAPI-06/07。

## 目标

首页进入任务工作台；能快速辨认任务进度、等待原因、最近成功/失败，以及所属项目和小节。用户可以按状态独立管理，按时间或项目分组查看，并从失败任务直接重试。

## 桌面构成

- 可折叠侧栏：突出“图像生产 / LoRA 训练”切换；一级入口项目、任务、预制、模板；全局模型、监控与日志、设置。
- 页头：任务标题和简洁范围说明，主要操作就近呈现。
- 状态筛选：全部、未提交、已提交、运行中、已暂停、已完成、失败、已取消，计数与文本结合。
- 工具栏：项目、小节/关键词、时间排序、项目分组与多选。
- 任务区域：项目分组标题、选择框、任务名称/小节、状态、等待原因、进度、耗时和适用操作。
- 详情：按需展开当前输入、Attempt、错误与阶段耗时，保持列表上下文。

## 状态约束

| 状态 | 页面表达 |
| --- | --- |
| 未提交 | 显示等待原因；可暂停或取消；不提示启动 ComfyUI |
| 已提交 | 显示已进入 ComfyUI 队列；读取外部权威状态 |
| 运行中 | 当前进度与耗时；暂停/取消须确认实际停止 |
| 已暂停 | 明确恢复从头执行 |
| 已完成 | 进入本任务图片审核；结果按项目/Section 可追溯 |
| 失败 | 可复制错误并重试同一任务；旧 Attempt 留存 |
| 已取消 | 可按既定终态清理规则管理 |

## 视觉与组件

默认主题跟随系统；首稿展示浅色和深色对照，不能将其中一个视为优先。图像生产青绿、LoRA 训练品红/粉，其余状态按标准语义色。采用柔和表面与紧凑但可读的信息布局。PrimeReact v10 对应 Button、Dropdown、SelectButton/TabView、Checkbox、DataTable、Tag、ProgressBar、Menu、Dialog/Sidebar；实际选用以页面适配为准，不把这份清单当作必须全部出现的控件。

## 移动构成

顶部保持模块识别与切换，底部四个主入口；任务列转换成易触摸的任务卡片，筛选收进独立面板；保留项目分组和状态入口，不压缩桌面表格。
