ComfyUI Manager 前端设计系统演示页面

设计特点

  • 黑白基调 + 青绿色（#10b981）+ 淡粉色（#f472b6）强调
  • 简化的 hover 效果：轻微上移 + 边框变色 + 轻微阴影
  • 深色/浅色模式切换（点击右上角图标）
  • 毛玻璃效果（backdrop-filter: blur(20px)）
  • 柔和动画（0.2s - 0.3s 过渡）
  • 响应式设计（桌面优先，移动端适配）
